## ⚙️ Setup Walkthrough

Setup is intentionally short. If you can unzip a folder, you can run this.

### Step 1 — Prepare the Ground
- Confirm your Windows build is **Windows 11 (any 2026 servicing update)** or **Windows 10 (22H2 or newer)**.
- Ensure Subnautica 2 is installed and has been launched at least once, so its save directory exists.
- Close any overlay-heavy software (streaming suites, aggressive antivirus widgets) temporarily. They occasionally fight for the same DirectX surface.

### Step 2 — Unpack the Companion
- Locate the archive you acquired via the download step above.
- Use the built-in Windows extractor (right-click → Extract All) or your preferred archiver.
- Choose a stable directory — something like `C:\DiveTools\WildTickStack\` is tidy. Avoid network drives and cloud-synced folders; they can cause the overlay's font cache to reload mid-dive.

### Step 3 — First Launch
- Open the extracted folder and locate the launcher executable.
- Right-click and choose **Run as administrator** on the very first launch. This lets the companion register its overlay hooks with the display compositor.
- A splash screen appears, followed by a tray icon. The tray icon is the suite's heartbeat — if it's there, the companion is alive.

### Step 4 — Pair with Your Game
- In the suite's main panel, click **Detect Game**. It scans common install paths automatically.
- If your install lives on a secondary drive, use **Browse** and select the folder containing the game executable.
- Once paired, a green dot appears next to the game name. You're connected.

### Step 5 — Tune to Taste
- Open **Settings → Overlay** to reposition, resize, or recolor any element.
- Open **Settings → Language** to switch interface language at any time; changes apply instantly.
- Open **Settings → Journal** to choose where expedition summaries are written.

### Step 6 — Dive
- Launch Subnautica 2 through Steam, Epic, or your platform of choice.
- The overlay fades in automatically once the main menu loads.
- Press your configured hotkey (default: `F8`) to toggle the overlay on and off during play.

## 🧪 Troubleshooting Reefs

**The overlay doesn't appear.**
Verify the companion is running (check the tray icon). Confirm the game was launched *after* the companion. Some platforms require game-first launch order.

**The overlay flickers or tears.**
Switch the game to Borderless Windowed mode. Exclusive fullscreen occasionally conflicts with third-party compositor layers.

**My antivirus flagged the launcher.**
Heuristic scanners sometimes distrust freshly downloaded executables. Add the install folder to your antivirus allowlist. The suite performs no network writes beyond optional opt-in telemetry.

**The journal is empty after a long session.**
Ensure the save directory is writable. If you use a platform that sandboxes saves, grant the companion read access to that folder.

**The map overlay drifts out of alignment.**
Recalibrate via **Settings → Overlay → Recalibrate**. This takes two seconds and re-syncs the overlay's coordinate space with the game's.

**Language didn't change.**
Some strings are baked into cached panels. Restart the companion after switching languages for a fully clean swap.
